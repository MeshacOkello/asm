Write a complete program, including `main`, that reads a count `n` and then `n` integers from stdin with `scanf`, and prints their sum with `printf`.

## Input

The first number is `n`, from 0 to 50. The next `n` numbers are signed 64-bit integers. Numbers are separated by any whitespace: spaces, tabs or newlines. The input is always well formed, and the sum always fits in a `long`.

## Output

The sum, as a decimal number, followed by a newline. Print nothing else: the output must match exactly.

## Example

Input:

```
3
1 2 3
```

Output:

```
6
```
